# 直流电路网表求解器

一个直流电路（DC）网表求解网页应用：Python + Flask + NumPy 后端，原生 JavaScript 前端。
用户在页面中逐行输入网表，提交后由**改进节点分析（MNA）**求解，显示各节点电压及各元件
按「起点 → 终点」方向的电流；并支持**灵敏度分析**：对 MNA 方程求导，给出观测量
（某节点电压或某元件电流）对每个元件数值的局部导数，以及元件数值改为原值 1.01 倍时
观测量的一阶变化量；还支持**两端口戴维南等效分析**：指定两个节点与负载电阻，
给出开路电压、等效电阻及带载后的端口电压、电流与负载功率；并支持**单电阻断路定位**：
输入若干非接地节点的实测电压与容差，枚举「正常电路」与「每个电阻单独断路」的假设，
按归一化误差得分找出与实测数据匹配的假设，定位断路元件。

## 快速启动

### 方式一：Docker Compose（单条命令）

```bash
docker compose up --build
```

### 方式二：Docker（单条命令）

```bash
docker build -t dc-circuit-solver . && docker run --rm -p 5000:5000 dc-circuit-solver
```

### 方式三：本地 Python

```bash
pip install -r requirements.txt
python app.py
```

启动后在浏览器访问：**http://localhost:5000**（端口 **5000**）

- 求解入口：页面上方「网表」输入框 + 「求解」按钮（`POST /solve`）；
- 灵敏度分析入口：同一页面「灵敏度分析」区块（`POST /sensitivity`）；
- 戴维南等效分析入口：同一页面「两端口戴维南等效分析」区块（`POST /thevenin`）；
- 单电阻断路定位入口：同一页面底部「单电阻断路定位」区块（`POST /diagnose-open`）；
- 四个入口的访问地址同为 **http://localhost:5000**。

## 网表格式

每行一个元件，字段以空白分隔：

```
名称 起点 终点 数值
```

| 名称首字母 | 元件 | 单位 | 说明 |
| --- | --- | --- | --- |
| `R` | 电阻 | Ω（欧姆） | 阻值必须为正数 |
| `V` | 理想电压源 | V（伏特） | 约定 起点电位 − 终点电位 ＝ 数值 |
| `I` | 理想电流源 | A（安培） | 正方向为 起点 → 终点 |

规则与限制：

- 节点 `0` 为接地节点，其余节点编号为任意非负整数；
- 最多 **12 个非接地节点**、**30 个元件**；
- 元件名称不得重复（不区分大小写），以字母开头，可含字母、数字、下划线；
- 同一元件的起点与终点不能相同；
- 电压源、电流源数值可为任意有限实数（含 0 与负数），电阻必须为正；
- 空行与 `#` 开头的注释行会被忽略。

示例：

```
V1 1 0 12
R1 1 2 6
R2 2 0 6
R3 2 3 12
I1 0 3 0.5
```

## 输出与错误处理

- **节点电压**：各非接地节点对地电压（节点 0 固定为 0 V）；
- **元件电流**：每个元件按「起点 → 终点」方向的电流（负值表示实际方向相反）；
- 输入格式或数值非法（字段数不对、名称重复、阻值非正、节点非法等）时，给出具体行号与原因；
- 电路无唯一解时说明原因，包括：浮动节点（未经电阻/电压源接地）、电压源构成回路
 （KVL 矛盾或电流不定）、电流源割集等；
- 出错时输入内容保留在文本框中，可直接修改后重新提交。

## 灵敏度分析

在页面「灵敏度分析」区块选择观测量并提交当前网表：

- **节点电压**：填写非接地节点编号（节点 0 电压恒为 0，不可观测）；
- **元件电流**：填写元件名称（不区分大小写），方向为「起点 → 终点」。

结果为观测量对**每个元件数值**的局部导数，以及该数值改为原值 **1.01 倍**时
观测量的一阶变化量（= 导数 × 0.01 × 原值），按变化量绝对值降序排列，
并标明单位与正负号。导数由当前 MNA 方程 `A·x = z` 求导得到
（`A·(dx/dp) = dz/dp − (dA/dp)·x`）：

- 电阻数值只改变导纳矩阵 `A`（`g = 1/R`，`dg/dR = −1/R²`）；
- 电压源、电流源数值只改变右端 `z`；
- 观测电阻电流时计入自身阻值的直接影响（`i = (v1−v2)/R` 分母含 `R`）；
- 观测电流源电流时，其对自身数值的导数为 1；
- 零值电源照常列出导数，其 1% 变化量为 0。

观测对象不存在（节点未出现、元件名不存在、观测接地节点等）时会说明原因，
网表与观测对象输入均保留，可修改后重新提交。

## 两端口戴维南等效分析

在页面「两端口戴维南等效分析」区块指定当前网表中两个**不同**的节点
（允许节点 `0`）与**正的有限**负载电阻 R_L（Ω），端口按
**第一节点（+）→ 第二节点（−）** 定义：

- **开路电压 Voc（V）**：`V(第一节点) − V(第二节点)`，由原网表 MNA 求解；
- **等效电阻 Rth（Ω）**：在原 MNA 系数矩阵上把独立源右端置零
  （理想电压源短路、理想电流源开路；**保留理想电压源的零伏约束行**），
  从第二节点向第一节点注入 1 A 试验电流后再解同一系数矩阵，
  `Rth = V(第一节点) − V(第二节点)`；端口被理想电压源短接时结果为 **0 Ω**；
- **负载电流 IL（A）**：正方向为**第一节点 → 第二节点**，
  `IL = Voc / (Rth + R_L)`，负值表示实际方向相反；
- **端口电压 VL（V）**：负载两端电压（第一节点侧为 +），`VL = IL × R_L`；
- **负载功率 PL（W）**：`PL = VL × IL`，恒为非负。

**反向选择**两个端点（交换第一、第二节点）时，Voc、VL、IL 变号，
Rth 与 PL 不变。节点不存在、两个端点相同、负载电阻非法（非数值、≤ 0、
无穷、NaN）或原网表无唯一解时，页面说明原因并保留网表与全部端口输入。

## 单电阻断路定位

在页面「单电阻断路定位」区块输入 **1～12 条不重复**的非接地节点实测电压，
每条含**有限电压值**与**正的有限绝对容差**（单位均为 V），随当前网表一起提交。
系统枚举以下假设并逐一重新求解：

- **正常电路**：所有元件按网表原样工作（正常电路必须有唯一解，否则直接报错）；
- **每个电阻单独断路**：**删除该电阻支路**，保留原节点集合重新组装 MNA
  （**不以大电阻近似**）。断路后无唯一解的假设（如支路删除后出现悬浮节点）
  单独列出原因，其余假设继续检查。

每个可求解假设给出各测点的预测值与**带符号误差**（预测 − 实测），
得分为各测点 **|误差| ÷ 容差** 的最大值，**得分 ≤ 1 视为匹配**。
结果按**得分**再按**假设名称**排序（无唯一解的假设列在最后）：

- **恰有一个匹配**：指出「电路正常」或具体断路元件（如「电阻 R1 断路」）；
- **多个匹配**：提示无法区分，列出全部候选假设；
- **没有匹配**：说明实测数据不符合「正常或单电阻断路」模型。

测点非法（数量不在 1～12、节点重复、接地节点、节点不存在、电压非有限值、
容差非正的有限值）时报错并保留网表与全部测点输入；诊断过程不会改写网表内容。

## 接口

`POST /solve`，请求体 `{"netlist": "<网表文本>"}`：

- 成功：`{"ok": true, "node_voltages": [{"node": 1, "voltage": ...}], "currents": [{"name": "R1", "kind": "R", "from": 1, "to": 2, "current": ...}]}`
- 失败：`{"ok": false, "error": "<原因>"}`

`POST /sensitivity`，请求体
`{"netlist": "<网表文本>", "observation": {"type": "voltage", "node": 2}}`
或 `{"netlist": "...", "observation": {"type": "current", "element": "R1"}}`：

- 成功：`{"ok": true, "observation": {"type": "voltage", "node": 2, "value": ..., "unit": "V"}, "sensitivities": [{"name": "R1", "kind": "R", "value": ..., "derivative": ..., "derivative_unit": "V/Ω", "delta": ..., "delta_unit": "V"}, ...]}`，
  其中 `sensitivities` 已按 `|delta|` 降序排列；
- 失败：`{"ok": false, "error": "<原因>"}`（网表校验、无唯一解、观测对象不存在等）。

`POST /thevenin`，请求体
`{"netlist": "<网表文本>", "node1": 2, "node2": 0, "load": 2.5}`
（`node1`/`node2` 为两个不同的节点编号，允许为 `0`；`load` 为正的有限负载电阻 Ω）：

- 成功：`{"ok": true, "thevenin": {"node_p": 2, "node_n": 0, "voc": 5.0, "voc_unit": "V", "rth": 2.5, "rth_unit": "Ω", "load": 2.5, "load_unit": "Ω", "vl": 2.5, "vl_unit": "V", "il": 1.0, "il_unit": "A", "pl": 2.5, "pl_unit": "W"}}`，
  其中电压、电流按第一节点（+）→ 第二节点（−）定义，电流正方向为第一节点 → 第二节点；
- 失败：`{"ok": false, "error": "<原因>"}`（节点不存在、两端点相同、负载非法、
  网表校验失败或无唯一解等）；交换两个端点时 `voc`/`vl`/`il` 变号，`rth`/`pl` 不变。

`POST /diagnose-open`，请求体
`{"netlist": "<网表文本>", "measurements": [{"node": 2, "voltage": 5.0, "tolerance": 0.1}, ...]}`
（`measurements` 为 1～12 条不重复的非接地节点实测电压，`voltage` 为有限值、
`tolerance` 为正的有限绝对容差，单位均为 V）：

- 成功：`{"ok": true, "results": [...], "matches": [...], "conclusion": {...}}`，其中
  - `results` 为全部假设：可求解假设含
    `{"hypothesis": "正常电路" 或 "R1 断路", "element": null 或 "R1", "solvable": true, "predictions": [{"node": 2, "measured": 5.0, "predicted": 5.0, "error": 0.0, "tolerance": 0.1, "ratio": 0.0}], "score": ..., "matched": ...}`，
    按（得分, 假设名称）排序；断路后无唯一解的假设为
    `{"hypothesis": ..., "element": ..., "solvable": false, "reason": "<原因>"}`，列在最后；
  - `score` 为各测点 `|error| / tolerance` 的最大值，`matched` 为 `score ≤ 1`；
  - `conclusion.type` 为 `normal`（仅正常电路匹配）/ `open`（仅某电阻断路匹配，
    附 `element`）/ `ambiguous`（多个匹配，附 `candidates`）/ `none`（无匹配）；
- 失败：`{"ok": false, "error": "<原因>"}`（网表校验失败、正常电路无唯一解、
  测点数量/节点/数值非法等）。
